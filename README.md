# Task 5: Deploy a Static Website Using GitHub Pages

## Project Overview

This project is a simple, responsive portfolio website built with HTML and CSS. It was created as a static website so it can be hosted for free using GitHub Pages.

The website includes:
- A header with a logo and navigation links.
- A hero section with an introduction and call-to-action buttons.
- An About section describing the website owner.
- A Skills section showing example skills.
- A Projects section with three sample project cards.
- A Contact section with an email link.
- A footer with copyright information.
- Responsive CSS so the layout adapts to smaller screens.

## Files in This Project

emilz360.github.io/

## Technologies Used

- **HTML5:** Structures the page into sections such as the header, hero, About, Projects, Contact, and footer.
- **CSS3:** Styles the website and controls its layout, typography, colors, hover effects, and responsive behavior.
- **Git and GitHub:** Track changes and store the project online.
- **GitHub Pages:** Publishes the static website to a public URL.

No database, server, JavaScript framework, or build step is required.

## How to Deploy on GitHub Pages

### Step 1: Enable GitHub Pages

1. Open the repository on GitHub.
2. Select **Settings**.
3. Select **Pages** in the sidebar.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/(root)` folder.
7. Click **Save**.

### Step 2: Visit the published website

Wait a few minutes for GitHub Pages to build and publish the site. The URL for the username-based repository will be:

https://emilz360.github.io

GitHub Pages hosts static files such as HTML, CSS, and client-side JavaScript. It does not run a Node.js/Express backend or a database. This project works on GitHub Pages because it is a static website.
